# Advent of Code 2026 in Kotlin

This project contains my attempts to solve the [Advent of Code 2026](https://adventofcode.com/2026) puzzles using [Kotlin](https://kotlinlang.org).

All code is *handcrafted*, no AI was used.

The input files for the puzzles are deliberately left out of the commits as per the [request](https://x.com/ericwastl/status/1465805354214830081) of puzzles' creator, [Eric Wastl](https://was.tl).

Commit messages are written in the [Conventional Commits](https://www.conventionalcommits.org/) format.
